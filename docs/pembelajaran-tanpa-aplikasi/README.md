# Pembelajaran tanpa aplikasi (model RMT)

Bahan cetak untuk mengajar teorema Pythagoras **tanpa aplikasi**, isinya sama dengan menu Belajar di aplikasi PELITA dan
mengikuti model **Rigorous Mathematical Thinking** (Kinard & Kozulin, 2008): Fase I Pengembangan Kognitif, Fase II Konten
sebagai Proses, Fase III Latihan Konstruksi Konseptual.
