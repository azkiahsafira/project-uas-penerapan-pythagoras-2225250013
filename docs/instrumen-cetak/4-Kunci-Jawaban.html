Memasukkan jawaban kertas ke analisis

Salin jawaban siswa ke file analisis/templat_kertas.csv (satu baris per lembar): kolom s1–s10 berisi huruf (A–D) atau angka seperti yang ditulis siswa; untuk kuesioner, kolom b1–b10 berisi angka 0–10. Lalu jalankan python analisis.py data.csv --kertas templat_kertas.csv. Jawaban dikoreksi otomatis memakai kunci yang sama.
